# EMBER Coffee

Современный адаптивный сайт кофейни в премиальном тёмном стиле.

## Возможности
- Адаптивный дизайн для компьютеров и смартфонов
- Интерактивное меню напитков
- Плавные анимации
- Разделы «О нас» и «Контакты»

## Технологии
HTML5, CSS3, JavaScript, OpenAI Codex.

## Демонстрация
https://musadark.github.io/ember-coffee/

## Статус
Демонстрационный проект для портфолио.
